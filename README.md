# \# FreeRTOS Learning Project

# 

# \## Описание

# 

# Этот репозиторий создан для практического изучения \*\*FreeRTOS\*\* на микроконтроллерах STM32.

# Основная цель — понять внутреннюю логику работы RTOS: планирование задач, синхронизацию и взаимодействие между ними.

# 

# \---

# 

# \## 

# 

# \*\*Этап 1 (текущий): Распределение задач (Task Management)\*\*

# 

# На данном этапе изучаются и отрабатываются:

# 

# \* создание задач (`xTaskCreate`)

# \* приоритеты задач

# \* планирование (scheduler)

# \* переключение контекста

# \* анализ поведения задач при разных приоритетах

# 

# Также проводится базовая трассировка переключения задач через:

# 

# \* `traceTASK\_SWITCHED\_IN`

# \* `traceTASK\_SWITCHED\_OUT`
